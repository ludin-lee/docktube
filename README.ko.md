# DockTube

[English](README.md) | **한국어**

맥 **Dock 아이콘 안에서** 유튜브 영상이나 영상 파일을 재생하는 작은 macOS 앱이에요.

![DockTube 아이콘](AppIcon.png)

## 다운로드 & 설치

1. **[DockTube.dmg 다운로드](https://github.com/ludin-lee/docktube/releases/latest/download/DockTube.dmg)**
2. 받은 `DockTube.dmg`를 열고, **DockTube**를 **Applications(응용 프로그램)** 폴더로 끌어다 놓으세요.
3. 응용 프로그램 폴더에서 DockTube를 실행하세요.

macOS 12 (Monterey) 이상, 애플 실리콘(M1 이후)과 인텔 맥 모두 지원해요.

### "열 수 없습니다" 경고가 뜨면

DockTube는 애플 개발자 서명이 없는 무료 앱이라, 처음 열 때 macOS가 막을 수 있어요.

1. 경고 창에서 **완료**(또는 취소)를 누르세요.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래로 내리면 "DockTube"가 차단되었다는 문구가 있어요. **그래도 열기**를 누르세요.
3. 다시 DockTube를 열고 **열기**를 누르면 돼요. 이 과정은 처음 한 번만 하면 돼요.

터미널에 익숙하다면 아래 명령 한 줄로도 돼요:

```bash
xattr -dr com.apple.quarantine /Applications/DockTube.app
```

## 사용법

앱은 **한국어, English, 日本語, 中文, Español**을 지원해요. 기본은 맥 언어 설정을 따르고, 우클릭 메뉴의 **🌐 Language**에서 언제든 바꿀 수 있어요.

앱을 켜면 유튜브 링크 입력 창이 떠요. 클립보드에 유튜브 링크가 있으면 자동으로 채워져요. 링크가 아닌 글자를 넣으면 유튜브에서 검색해요.

| 동작 | 결과 |
| --- | --- |
| Dock 아이콘 **클릭** | 재생 / 일시정지 (재생 중인 영상이 없으면 링크 입력 창) |
| Dock 아이콘 **우클릭** | 메뉴 열기 |

### 우클릭 메뉴

- **재생 / 일시정지**
- **음소거**
- **시간 이동… (현재 / 전체)** — 슬라이더로 원하는 위치를 골라 이동
- **⏪ 10초 뒤로 / ⏩ 10초 앞으로**
- **⏮ 이전 영상 / ⏭ 다음 영상** — 재생목록에서는 목록 순서대로, 영상 하나만 틀었을 때는 다음 = 유튜브 추천 영상, 이전 = 방금 보던 영상 (쇼츠 모드에서는 **⏮ 이전 쇼츠 / ⏭ 다음 쇼츠**)
- **재생목록 (현재/전체)** — 목록에서 영상 제목을 눌러 바로 이동
- **화질** — `자동` / `최고 화질 고정` / `1080p 고정`, 또는 그 영상이 제공하는 화질(예: 1080p60, 720p) 중에서 골라요. 고른 화질이 없는 영상이면 그 아래에서 가장 좋은 화질로 나와요. 앱을 다시 켜도 기억해요
- **자막** — 유튜브 자막 켜기/끄기 (기본은 꺼짐). 바꾸면 플레이어를 다시 불러와서 보던 곳부터 이어서 재생해요. 앱 언어의 자막이 있으면 그 언어로 나와요
- **유튜브 링크 열기…**
- **🔍 유튜브 검색…** — 검색 결과가 썸네일·제목·채널·길이와 함께 메뉴로 떠요. 누르면 바로 재생
- **쇼츠 피드 보기** — 유튜브 쇼츠를 브라우저처럼 넘기면서 봐요 (아래 "쇼츠 모드" 참고)
- **유튜브 로그인… / 유튜브 로그아웃** — 로그인 안 돼 있으면 영상 창에 구글 로그인 화면을 띄워요. 로그인하면 내 계정 추천 쇼츠가 나와요. 로그인돼 있으면 로그아웃이 보이고, 누르면 앱에 저장된 쿠키·사이트 데이터를 모두 지워요
- **영상 파일 열기…** — mp4, mov 등 로컬 영상
- **아이콘 꽉 채우기** — 켜면 아이콘을 꽉 채우고(가장자리 잘림), 끄면 영상 전체가 보여요
- **미니 플레이어** — Dock 바로 위에 가로로 긴 작은 영상 창을 띄워요 (아래 참고)
- **영상 창 보기** — 숨어 있는 실제 영상 창을 보여줘요. 빨간 닫기 버튼을 누르면 다시 숨어요
- **🌐 Language** — 자동(시스템 언어) / 한국어 / English / 日本語 / 中文 / Español. 앱을 다시 켜도 기억해요
- **업데이트 확인…** — GitHub에서 새 버전이 있는지 바로 확인해요 (현재 버전도 같이 보여요)
- **자동 업데이트** — 기본 켜짐 (아래 "업데이트" 참고)

### 미니 플레이어

- 드래그로 옮기고, 가장자리를 끌어 크기를 바꿔요 (16:9 유지). 위치와 크기는 기억해요.
- 더블클릭하면 재생/일시정지, 우클릭하면 Dock 메뉴와 같은 메뉴가 떠요.
- 마우스를 올리면 조작 UI가 스르륵 나타나요:
  - 오른쪽 위 **✕** — 미니 플레이어 닫기 (다시 켜려면 우클릭 메뉴 → 미니 플레이어)
  - 빨간 **타임바** — 마우스를 올리면 두꺼워지고, 끌어서 원하는 시간으로 이동
  - **⏮ ⏯ ⏭** — 이전 / 재생·일시정지 / 다음
  - **🔊 음량** — 스피커를 누르면 음소거, 흰 바로 음량 조절 (유튜브·쇼츠·영상 파일 모두 적용, 앱을 다시 켜도 기억)

### 지원하는 유튜브 주소

- `https://www.youtube.com/watch?v=...`
- `https://youtu.be/...`
- `https://www.youtube.com/shorts/...` (쇼츠 모드로 열려요)
- `.../embed/...`, `.../live/...`
- 11자리 영상 ID만 넣어도 돼요
- 재생목록: `https://www.youtube.com/playlist?list=...` — 차례대로 재생돼요. `watch?v=...&list=...`처럼 둘 다 있으면 그 영상부터 시작해요

영상 하나만 틀었을 때는 끝나면 유튜브 추천 다음 영상이 자동으로 이어서 나와요. 우클릭 메뉴의 **자동으로 다음 영상**을 끄면 처음부터 반복 재생돼요 (앱을 다시 켜도 기억해요). 재생목록은 마지막 영상이 끝나면 첫 영상으로 돌아가요.

### 쇼츠 모드 (실험 기능)

`https://www.youtube.com/shorts/...` 링크를 넣거나 **쇼츠 피드 보기**를 누르면, 임베드 플레이어 대신 실제 유튜브 쇼츠 페이지를 열어요.

- **⏭ 다음 쇼츠 / ⏮ 이전 쇼츠**로 브라우저에서 넘기듯 추천 쇼츠를 볼 수 있어요.
- **자동으로 다음 쇼츠** (기본 켜짐) — 쇼츠가 끝나면 다음 쇼츠로 넘어가요. 끄면 한 쇼츠를 반복해요. 앱을 다시 켜도 기억해요.
- 한 번 **유튜브 로그인…** 해 두면 앱을 껐다 켜도 로그인이 유지되고, 내 계정 기준 추천이 나와요.
- 재생/일시정지, 음소거, 시간 이동은 되고, 화질·자막·재생목록 메뉴는 이 모드에서 안 보여요.

## 업데이트

DockTube는 이 저장소의 [GitHub 릴리스](https://github.com/ludin-lee/docktube/releases)에서 스스로 업데이트해요.

- **자동 업데이트** (기본 켜짐) — 앱을 켜고 10초 뒤, 그리고 하루에 한 번 확인해요. 새 버전이 있으면 **업데이트** / **나중에**를 물어봐요. *나중에*를 누른 버전은 자동 확인에서 다시 묻지 않아요.
- **업데이트 확인…** — 지금 바로 확인해요.
- **업데이트**를 누르면 새 `DockTube.dmg`를 받아 앱을 바꿔 끼우고 다시 켜요. 앱이 잠깐 꺼지니 재생이 멈춰요.
- 앱이 있는 폴더에 쓸 권한이 없는 등 스스로 바꿀 수 없으면, 릴리스 페이지를 열어서 직접 받게 안내해요.
- 1.1 이하 버전에는 업데이트 기능이 없어서, 1.2는 한 번 직접 받아서 설치해야 해요.

## 직접 빌드하기 (개발자용)

Xcode 명령줄 도구가 필요해요 (`xcode-select --install`).

```bash
bash build.sh        # DockTube.app 만들기 (애플 실리콘 + 인텔 유니버설)
bash build.sh dmg    # 배포용 DockTube.dmg까지 만들기
open DockTube.app
```

### 동작 방식

- 유튜브는 보이지 않는 `WKWebView`에서 IFrame API로 재생하고, 초당 30번 스냅샷을 찍어 Dock 아이콘에 그려요.
- 영상 파일은 `AVPlayer`로 재생하고 프레임을 직접 꺼내 아이콘에 그려요.
- 영상 창은 화면 구석에 거의 투명(alpha 0.01)하게 떠 있어요. 완전히 숨기면 macOS가 화면 그리기를 멈춰서 아이콘이 멈추거든요.

### 파일 구성

| 파일 | 설명 |
| --- | --- |
| `DockTube.swift` | 앱 전체 소스 (단일 파일) |
| `build.sh` | `.app` 번들과 배포용 `.dmg`를 만드는 빌드 스크립트 |
| `AppIcon.icns` / `AppIcon.png` | 앱 아이콘 (재생 전 Dock에 표시) |

## 알려진 제약

- 유튜브 재생에는 인터넷 연결이 필요해요.
- 임베드가 막힌 유튜브 영상은 재생되지 않아요.
- 믹스(`list=RD...`)나 비공개 재생목록은 재생되지 않을 수 있어요. 아주 긴 재생목록은 앞부분만 보일 수 있어요.
- 화질은 유튜브 공식 API가 아닌 플레이어 내부 기능으로 바꿔요. 유튜브가 바꾸면 화질 메뉴가 안 보이거나 안 먹힐 수 있어요. Dock 아이콘은 작아서 화질 차이가 거의 안 보이고, 주로 미니 플레이어·영상 창과 데이터 사용량에 영향이 있어요.
- 자막은 유튜브만 지원해요. 자막이 없는 영상에서는 켜도 아무것도 안 나와요.
- 자동 다음 영상은 유튜브 영상 페이지에서 "자동재생 다음 영상"을 읽어 와요. 유튜브가 페이지 형식을 바꾸면 못 찾을 수 있고, 그땐 처음부터 반복 재생돼요. 로그인과 상관없는 일반 추천이에요.
- 쇼츠 모드는 유튜브 웹페이지를 직접 다뤄서, 유튜브가 페이지를 바꾸면 넘기기가 안 될 수 있어요. 영상 위 제목 같은 글자가 아이콘에 같이 찍힐 수 있고, 구글이 앱 안 로그인을 막을 수도 있어요.
